## 1. Введение

### 1.1. Назначение документа
Документ описывает функциональные и нефункциональные требования к приложению ShadowFox Eng в состоянии на момент выпуска версии 1.0.0. Служит основой для доработок, тестирования и публикации в магазинах приложений (RuStore, Google Play).

### 1.2. Область применения
ShadowFox Eng — мобильное веб-приложение (PWA), упакованное в Android-приложение по технологии Trusted Web Activity. Назначение — расширение словарного запаса английского языка у русскоязычных пользователей, уже знакомых с основами, до уровня B1–B2 за счёт интервальных повторений, разнообразных проверок и голосового режима без рук.

### 1.3. Термины и сокращения
| Термин | Значение |
|---|---|
| PWA | Progressive Web App — веб-приложение, устанавливаемое на устройство и работающее офлайн |
| TWA | Trusted Web Activity — способ упаковки PWA в Android-приложение, внутри которого работает Chrome |
| SRS-интервалы | Интервальные повторения (spaced repetition) — показ слова с растущими промежутками |
| Ячейка (box) | Уровень усвоения слова 0–6 по системе Лейтнера |
| Порция | Набор из 5 новых слов, изучаемых за один заход |
| Сессия | Последовательность вопросов одной проверки или одного запуска режима «В дороге» |
| Piper | Открытый нейросетевой синтезатор речи, работающий в браузере через WebAssembly |
| Сцена | Анимированный векторный фон приложения |
| Токен | CSS-переменная цвета темы |

## 2. Общее описание

### 2.1. Место продукта
Самостоятельное приложение без серверной части. Все данные хранятся на устройстве. Внешние сервисы используются только по инициативе пользователя (онлайн-голоса по ключу, загрузка офлайн-голосов).

### 2.2. Основные функции
1. Изучение новых слов карточками порциями по 5 с немедленной проверкой.
2. Интервальные повторения по 7 ячейкам.
3. Семь видов проверки и экзамен.
4. Голосовой режим «В дороге» с голосовыми командами.
5. Пометка сложных слов и отдельные тренировки по ним.
6. Каталог 1000 слов с поиском и управлением прогрессом.
7. Озвучка четырьмя типами голосов (системные, встроенные офлайн, Google Cloud, ElevenLabs).
8. Настраиваемое оформление: четыре анимированные сцены, ночная и дневная темы.
9. Перенос прогресса между устройствами кодом.

### 2.3. Пользователи
Русскоязычные взрослые и подростки с английским на уровне A2 и выше. Используют телефон, часто в движении (пешком, велосипед, транспорт), иногда без интернета.

### 2.4. Среда выполнения
- Android 8.0 и новее — поддерживаемые версии для текущего APK на Capacitor. Поддержка Android 7 не заявлена; сведения о TWA ниже относятся к исторической версии 1.0.
- Любой современный браузер на Android, iOS, Windows, macOS — через сайт.
- Распознавание речи: Chrome (Android/desktop), Safari (iOS 14.5+). В Firefox недоступно.

### 2.5. Ограничения
- Нет серверной части: синхронизация между устройствами только ручным кодом.
- Приложение не работает в фоне при заблокированном экране (ограничение браузера); режим «В дороге» держит экран включённым через Wake Lock.
- Распознавание речи требует интернета (обрабатывается сервисом ОС).
- Встроенные офлайн-голоса загружаются с huggingface.co; при недоступности сайта загрузка невозможна.

### 2.6. Допущения
- На устройстве установлен хотя бы один системный голос для английского и русского (иначе озвучка недоступна до установки).
- У пользователя есть микрофон и он разрешает доступ к нему для голосовых режимов.

## 3. Функциональные требования

Обозначения: **FR-x.y** — требование; приоритет: **M** — обязательно, **S** — желательно.

### 3.1. Словарь и данные

| ID | Требование | Приоритет |
|---|---|---|
| FR-1.1 | Основная программа — Oxford 3000: 3810 единиц «слово + часть речи» (A1 1076, A2 992, B1 907, B2 835) из официального списка (`tools/oxford-3000.json`), разбитых по уровням на тематические блоки по 20–25 единиц. Значения, которые Oxford разделяет, — отдельные карточки. Слова прежнего курса вне списка — «Дополнительный словарь» (482 слова по прежним 20 темам). Уровень без контента показывается как «готовится». См. `docs/OXFORD_PROGRAM.md`. | M |
| FR-1.2 | Каждое слово имеет: английское написание, русский перевод (возможно несколько через запятую или точку с запятой), часть речи, пример-предложение на английском, перевод примера на русский. | M |
| FR-1.3 | Прогресс привязан к ключу «слово\|часть речи» (для разделённых значений — с ярлыком значения), а не к позиции в списке. Прогресс формата v2 (ключ — слово) переносится на новые ключи один раз при загрузке или импорте. | M |
| FR-1.5 | У слова могут быть необязательные устойчивые сочетания и запасные примеры (`practice`) и пары близких значений (`confusables`); они дают задания «Устойчивые сочетания» и «Близкие значения» и дополнительные примеры для сложных слов. | S |
| FR-1.4 | Многословные единицы (фразовые глаголы, устойчивые сочетания) обрабатываются наравне с одиночными словами во всех режимах. | M |

### 3.2. Изучение новых слов

| ID | Требование | Приоритет |
|---|---|---|
| FR-2.1 | Пользователь выбирает уровень (A1–B2, Доп.) и блок плитками; на плитке виден прогресс блока; повторное нажатие на выбранную плитку не перерисовывает экран. | M |
| FR-2.1a | Стартовая проверка: выбор стартового уровня; для A2 и выше — 15 вопросов (10 «выбор перевода», 5 «обратный выбор») по словам уровня без записи в прогресс. При 12+ верных все слова более низких уровней и верно узнанные слова помечаются условно известными (`known:1`, ячейка 6, повторение через 30–120 дней случайно), текущий блок — первый блок уровня; иначе предлагается уровень ниже или повтор. Результат хранится в `S.placement` и входит в копию прогресса. Условно известные слова не считаются в достижениях, пока не подтверждены самостоятельным ответом. | M |
| FR-2.2 | Порция — 5 ещё не начатых слов выбранного уровня (меньше, если осталось меньше). | M |
| FR-2.3 | Карточка показывает слово, часть речи, уровень и озвучку; по тапу переворачивается (3D) и показывает перевод, пример с подсветкой слова, перевод примера, озвучку примера и кнопку «сложное». | M |
| FR-2.4 | Кнопка «Дальше» при неперевёрнутой карточке сначала переворачивает её; при перевёрнутой — переводит слово в ячейку 0 со сроком «сегодня» и открывает следующее. | M |
| FR-2.5 | Кнопка «Уже знаю» помечает слово условно известным: ячейка 5, проверка через 14 дней; верный самостоятельный ответ снимает пометку и закрепляет слово, ошибка возвращает его в обычный цикл. | M |
| FR-2.6 | После порции автоматически запускается мини-проверка «выбор перевода» по словам порции; результаты влияют на ячейки. | M |
| FR-2.7 | Слово озвучивается автоматически при показе, если включена настройка «Озвучивать автоматически». | S |

### 3.3. Интервальные повторения

| ID | Требование | Приоритет |
|---|---|---|
| FR-3.1 | Ячейки 0–6 с интервалами 0, 1, 3, 7, 14, 30, 60 дней. Верный ответ — ячейка +1; ошибка — ячейка −2 (не ниже 0). Срок следующего показа = сегодня + интервал новой ячейки. | M |
| FR-3.2 | Статусы: «не начато» (нет записи), «учу» (ячейка 0–2), «знаю» (3–5), «закреплено» (6). | M |
| FR-3.3 | Список «на повторение» — слова с ячейкой < 6, у которых срок ≤ сегодня. | M |
| FR-3.4 | Сессия повторения берёт до 15 слов; вид вопроса зависит от ячейки: 0–1 выбор перевода, 2 обратный выбор, 3 на слух (или пропуск при отсутствии озвучки), 4+ написание. | M |
| FR-3.5 | Ведётся дневная статистика: новые слова, ответы, верные/неверные; серия дней подряд обновляется при любой активности. | M |

### 3.4. Проверки

| ID | Требование | Приоритет |
|---|---|---|
| FR-4.1 | Выборка слов для проверки: «Повтор» (на повторение), «Начатые», «Сложные», «Уровень» (плитки). Минимум 4 слова, иначе сообщение. | M |
| FR-4.2 | Режим «Выбор перевода»: английское слово → 4 русских варианта; отвлекающие варианты предпочтительно той же части речи, без дублей. | M |
| FR-4.3 | Режим «Обратный выбор»: русский перевод → 4 английских варианта. | M |
| FR-4.4 | Режим «Написание»: ввод английского слова по переводу; засчитывается точное совпадение (без учёта регистра) или одна опечатка при длине ≥ 5; подсказка показывает пример с первой буквой. | M |
| FR-4.5 | Режим «На слух»: слово озвучивается, выбор из 4 английских вариантов; повторное прослушивание по кнопке. | M |
| FR-4.6 | Режим «Произношение»: показ слова и образца; запись с микрофона; засчитывается, если хотя бы один вариант распознавания совпал (точно, как целое слово внутри фразы или с одной опечаткой). Без распознанной речи — повтор без штрафа. | M |
| FR-4.7 | Режим «Пары»: 5 английских и 5 русских карточек; верная пара исчезает и озвучивается; неверная трясётся; слово, ошибочно сопоставленное хотя бы раз, считается отвеченным неверно. | M |
| FR-4.8 | Режим «Пропуск в предложении»: пример с вырезанным словом (с учётом словоформ: -s, -ed, -ing и др.), выбор из 4 английских вариантов; слова без совпадения формы в примере исключаются из выборки. | M |
| FR-4.9 | Режим «Экзамен»: 20 вопросов, виды чередуются (выбор, обратный, написание, пропуск, на слух). | M |
| FR-4.10 | После каждого ответа — блок обратной связи: верно/неверно, слово и перевод, при ошибке — пример с переводом; кнопка «сложное»; кнопка «Дальше», при верном ответе автопереход через 0,7 с. | M |
| FR-4.11 | Экран результатов: процент (анимированный счётчик), число верных, вердикт, список ошибок с видом вопроса; кнопки «На главную» и «Ещё раз». | M |
| FR-4.12 | Варианты ответа можно выбирать клавишами 1–4 на физической клавиатуре. | S |
| FR-4.13 | Точность по каждому виду проверки накапливается и показывается на главной. | S |

### 3.5. Режим «В дороге»

| ID | Требование | Приоритет |
|---|---|---|
| FR-5.1 | Три подрежима: «Слушать» (слово → перевод → пример, без микрофона), «Отвечать по-русски» (слышит английское, говорит перевод), «Отвечать по-английски» (слышит перевод, говорит слово). | M |
| FR-5.2 | Выборки: новые слова текущего уровня (до 10), на повторение, сложные, все начатые, уровень по выбору (до 20). | M |
| FR-5.3 | Голосовые команды на языке ответа: пропустить («дальше»/next), повторить («повтори»/repeat), пример, подсказка («перевод»/hint), пауза («стоп»/stop). | M |
| FR-5.4 | Экранные кнопки «Пауза/Продолжить» и «Дальше» увеличенного размера (не менее 76 px высотой). | M |
| FR-5.5 | Русские ответы сверяются гибко: по любому из вариантов перевода, с допуском одной ошибки на 5 символов и по совпадению основы слова (окончания могут отличаться). | M |
| FR-5.6 | При отсутствии ответа дважды подряд слово считается неотвеченным, произносится правильный ответ. | M |
| FR-5.7 | При недоступности микрофона режим ставится на паузу с голосовым и текстовым сообщением. | M |
| FR-5.8 | Во время режима удерживается Wake Lock экрана; по завершении — отчёт (верно N из M) голосом и экраном результатов. | M |
| FR-5.9 | В подрежиме «Слушать» новые слова после прочтения переводятся в ячейку 0. | S |

| ID | Требование | Приоритет |
|---|---|---|
| FR-9a.1 | На главной над остальными режимами — кнопка «Занятие на сегодня» с оценкой длительности (~20 с на повторение, ~45 с на новое слово, ~15 с на разбор ошибки) и составом: повторить N → новых M → разбор ошибок. Та же кнопка есть в домике лисы. | M |

| FR-9a.3 | Показатели дня: слов к повторению, «вспомнил сам» сегодня и за неделю, список регулярно забываемых слов (3+ ошибки, ячейка не выше 2) с переходом в карточку слова. | M |

## 4. Нефункциональные требования

| ID | Требование |
|---|---|
| NFR-1 | **Офлайн.** После первого запуска приложение открывается без сети (service worker, стратегия «сеть, затем кэш»). Скачанные офлайн-голоса и кэш озвучки работают без сети. |
| NFR-2 | **Производительность.** Первый экран отрисовывается менее чем за 1 с на среднем телефоне; синтез Piper — не более 0,5 с на фразу после инициализации (≈1,5 с); стеклянные эффекты не должны опускать скролл ниже 30 к/с. |
| NFR-3 | **Размер.** Основной код и словарь — < 500 КБ; движок офлайн-голосов (32 МБ) грузится только при первом обращении к встроенным голосам; голос — 63 МБ. |
| NFR-4 | **Приватность.** Нет регистрации, аналитики, рекламы, серверного хранения. Ключи API и прогресс — только на устройстве. Описано в политике конфиденциальности. |
| NFR-5 | **Совместимость.** Chrome/Android, Safari/iOS, десктопные Chrome/Edge/Safari; Firefox — без распознавания речи. Ширина экрана от 320 px; макет — одна колонка до 520 px. |
| NFR-6 | **Доступность.** Видимое состояние фокуса, `aria-label` у иконочных кнопок, уважение `prefers-reduced-motion`, минимальная высота кликабельных элементов 40 px (основные — 48 px, в дороге — 76 px). |
| NFR-7 | **Локализация.** Интерфейс — русский; изучаемый язык — английский. |
| NFR-8 | **Устойчивость.** Ошибки внешних сервисов не ломают сессию: переход на системный голос, сообщение, пауза. |
| NFR-9 | **Обновляемость.** Обновление кода на сайте применяется в APK при следующем запуске без переустановки. Версия кэша service worker увеличивается при каждом выпуске. |
| NFR-10 | **Лицензии.** Голоса Piper — открытые лицензии (у части русских — некоммерческие: приложение остаётся бесплатным без рекламы). Иллюстрации — с разрешения авторов. |

## 5. Внешние интерфейсы

### 5.1. Пользовательский интерфейс
- Портретная ориентация, одна колонка, нижняя панель вкладок, нижние выезжающие панели для настроек, карточки слова, подтверждений и мастера подключения.
- Шрифты: Fraunces (английские слова), Golos Text (интерфейс), с системными запасными.
- Палитра: уголь #14171C, оранжевый #E8853A, янтарь #EFA537, жёлтый #F2C230; светлая тема — тёплая бумага #F6F1EA.

### 5.2. Аппаратные интерфейсы
Микрофон (Web Speech API `SpeechRecognition`), динамик, вибромотор (`navigator.vibrate`), удержание экрана (`Wake Lock API`).

### 5.3. Программные интерфейсы
| Сервис | Назначение | Условие |
|---|---|---|
| Web Speech API (синтез и распознавание) | системные голоса, распознавание речи | встроено в браузер |
| huggingface.co (`diffusionstudio/piper-voices`) | загрузка моделей Piper | по запросу пользователя |
| Google Cloud Text-to-Speech REST v1 | онлайн-голоса | ключ пользователя |
| ElevenLabs API v1 | онлайн-голоса | ключ пользователя |
| Google Fonts | шрифты | при наличии сети, с запасным стеком |

### 5.4. Формат данных на устройстве
`localStorage["shadowfox.v2"]` — JSON: `{v:2, goal, streak:{n,last}, days:{дата:{n,q,ok,bad}}, w:{слово:{box,due,ok,bad}}, hard:{слово:1}, modes:{режим:{ok,bad}}, set:{auto,theme,scene,motion,rate,enVoice,ruVoice,tts:{en,ru},ttsKeys}}`. Голоса Piper — OPFS; аудио — Cache API `shadowfox-tts-v2`; файлы приложения — Cache API `shadowfox-v4`.
