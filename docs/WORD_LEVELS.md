# Подтверждённые уровни слов в тематических маршрутах

Метки CEFR — справочная оценка слова и части речи по Oxford 3000/5000.
Они не вычисляются из номера карточки, номера маршрута или количества изученных слов.
Сложность отдельного значения и конкретного предложения может отличаться от оценки леммы.

## Источники

- [The Oxford 3000](https://www.oxfordlearnersdictionaries.com/external/pdf/wordlists/oxford-3000-5000/The_Oxford_3000.pdf), Oxford University Press, A1–B2.
- [The Oxford 5000, дополнительные 2000 слов](https://www.oxfordlearnersdictionaries.com/external/pdf/wordlists/oxford-3000-5000/The_Oxford_5000.pdf), Oxford University Press, B2–C1.
- [Описание методики списков](https://www.oxfordlearnersdictionaries.com/about/wordlists/oxford3000-5000).

Проверено 21.09.2026. В `word-levels.js` сохранены ссылки, контрольные суммы PDF,
номер страницы и исходная строка для каждой принятой оценки. PDF в приложение не входят.
Таблица включает только слова используемых маршрутов, а не полные списки Oxford.

Текущее покрытие: **652 из 867 уникальных сочетаний слова и части речи**, или
**781 из 1000 карточек**. У остальных 219 карточек метки нет.

## Правила сопоставления

1. Только точное совпадение английского написания и части речи; регистр и Unicode нормализуются.
2. Уровни разных частей речи разделены. Одинаковые слово и часть речи во всех маршрутах имеют одинаковую метку.
3. Если в источниках есть конфликтующие оценки одной пары, автоматическая метка не назначается.
4. Записи с уточнённым значением в скобках не сопоставляются автоматически: сначала нужна ручная проверка русского значения. Нет догадок по частотности, словообразованию или номеру карточки.
5. Нет записи — `null` в поле уровня, без метки в интерфейсе. Это не означает C1 и не означает ошибку загрузки.
6. Порядок карточек и ключи сохранённого прогресса не меняются.

Примеры: `carbon` (n) — B2, `recycle` (v) — A2, `browser` (n) — C1.
У `settings` (n) нет точной записи в этих списках; уровень для `setting` ему не приписывается.

## Обновление

Скачать два PDF по ссылкам выше. В окружении с Python, `pypdf` и Node.js выполнить из корня проекта:

```bash
python tools/import-word-levels.py /path/to/The_Oxford_3000.pdf /path/to/The_Oxford_5000.pdf --checked-at 2026-09-20
```

Проверить diff, контрольные суммы источников, примеры разных частей речи и неоднозначные значения.
Запустить `npm test` и `npm run build:web`. При публикации новой таблицы повысить версию кэша в `sw.js`.
Для APK таблица упаковывается локально, интернет при показе карточек не требуется.
