# Изменения 1.0.3.3 → 1.0.3.4

Дата: 14 сентября 2026. Ветка `fox-1.0.3.4-fixes`, PR https://github.com/Teninz/english-1000/pull/1.
Поводом стала проверка версии 1.0.3.3 (первая с лисой-компаньоном) в браузере с эмуляцией телефона 375×812.

## Что было не так и что исправлено

### 1. Ручка лисы ломала занятие
- **Симптом.** Круглая ручка с мордочкой лисы справа оставалась на экране во время урока и перекрывала угол карточки. Если тапнуть её посреди урока, в панели появлялась кнопка «Продолжить занятие»; она вызывала `journeyStart()` → `endSession()`, и карточки начинались заново с 1/5.
- **Правка.** `companion.css`: во время сессии ручка скрыта — `body:has(.sess-top) .fox-handle{display:none}`. Открыть панель можно только с главной.

### 2. Неверный текст в финале первого занятия
- **Симптом.** По окончании первого занятия дня лиса писала «Сегодняшняя встреча уже отмечена» вместо «В корзинке появилось угощение», хотя угощение начислялось. Причина: день отмечался ещё внутри проверки (`maybeCompleteLesson`), и к финалу признак «первое занятие» уже был потерян.
- **Правка.** `journey.js`: при старте занятия в план записывается `plan.firstOfDay` (было ли занятие сегодня до старта), финал читает его. Проверено: угощения 2 → 3, текст верный.

### 3. Светлая тема: заголовок панели не читался
- **Симптом.** Шапка панели «Домик лисы» имела жёстко заданный тёмный градиент `#202633`; в светлой теме текст заголовка тёмный — получалось тёмное на тёмном.
- **Правка.** `companion.css`: градиент начинается с `var(--surface-2)` — цвет берётся из активной темы.

### 4. Прокрутка под открытой панелью
- **Симптом.** При долистывании панели до конца на телефоне начинала ехать главная страница за ней.
- **Правка.** `companion.css`: `body.fox-drawer-open{overflow:hidden}` и `overscroll-behavior:contain` у `.fox-drawer`.

## Прочее
- `about.js`: версия `1.0.3.4`; в «О приложении» добавлен раздел «Лиса-компаньон» (как работает панель, настроение, награды, виджет). Верхняя запись списка изменений переименована в 1.0.3.4, содержимое прежнее.
- `android/app/build.gradle`: `versionCode 13`, `versionName "1.0.3.4"`.
- `sw.js`: кэш `shadowfox-v12` (изменились веб-файлы).
- `docs/HANDOFF.md`: зафиксировано, что 3D-модель лисы из пакета `Free/` — временная, для проверки механики; курс на 2D-лису с главной страницы; пометка не публиковать в магазин с этой моделью, пока не найдена её лицензия.

## Что проверено
- `npm test` — 23 из 23.
- В браузере: светлая тема панели читается; во время урока ручка скрыта; полный цикл занятия (5 карточек → проверка → финал) завершается верным текстом, награда «Первый лист» выдаётся, анимация `happy` играет.
- `npm run build:web` и `npx cap sync android` выполнены без ошибок.

## Что не менялось
- Логика настроения и угощений (JS и Kotlin совпадают).
- Android-виджет лисы, `CompanionStore.kt`, `WidgetPlugin.java`.
- Арт: остаются те же 3D-рендеры, замена на 2D — отдельная задача (см. `docs/NEXT_STEPS.md`).
