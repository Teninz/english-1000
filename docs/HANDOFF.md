## Как выпустить новую версию (10 минут)

1. Правки в веб-файлах и/или `android/`.
2. Поднять `versionCode` (+1) и `versionName` в `android/app/build.gradle`; ту же строку в `const APP_VERSION` в `about.js`; при изменении веб-файлов — имя кэша в `sw.js` (`shadowfox-vN`).
3. Добавить пункт в `CHANGELOG` в `about.js` — **в запись текущей публикуемой версии**, промежуточные номера в магазин не идут.
4. `npm run build:web && npx cap sync android`, коммит, `git push`.
5. Дождаться workflow «Android APK», `gh run download <id>`, положить в `apk/`, отправить пользователю.
6. Для RuStore: консоль → Версии → Загрузить → APK; ключ тот же, версия встанет как обновление.

Пиксельные папки `art/companion` и `art/companion-anim` исключены из сборки, но лежат в репозитории — можно удалить.
