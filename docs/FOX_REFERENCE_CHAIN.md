# Эталонная цепочка анимации лисы

Первый производственный эталон — цепочка `idle → notice → happy → settle → idle`. Она проверяет характер, взгляд, пластику, безопасные границы кадра и плавный возврат в общую позу до выпуска десятков отдельных анимаций.

Визуальный эталон: `tools/companion-source/reference-chain-v1.png`. Это лист ключевых поз, а не готовый спрайт для приложения.

## Формат

- 5 секунд, 20 кадров/с, итого 100 последовательных кадров.
- Логический холст одного кадра: 256 × 256 px, прозрачный фон.
- Видимая лиса занимает не более 224 × 224 px; по периметру остаётся минимум 16 px прозрачного поля.
- Уши, хвост, лапы, шарф и лист ни в одном кадре не пересекают границу safe area.
- Экспорт: один WebP-атлас с метаданными кадров. APNG остаётся только временным форматом совместимости.
- В памяти декодируется только текущая цепочка и следующий переход. При `prefers-reduced-motion` и в режиме экономии используется статичный ключевой кадр.

## Тайминг 100 кадров

| Кадры | Время | Действие |
|---:|---:|---|
| 0–15 | 0,00–0,75 c | Спокойное дыхание, взгляд на пользователя. Кадр 0 — общая нейтральная поза. |
| 16–27 | 0,80–1,35 c | Короткое моргание, одно ухо поворачивается к пользователю. |
| 28–39 | 1,40–1,95 c | Фокус взгляда, корпус чуть подаётся вперёд; подготовка к подъёму. |
| 40–57 | 2,00–2,85 c | Мордочка и грудка поднимаются, уши расправляются, хвост отвечает с задержкой. |
| 58–69 | 2,90–3,45 c | Радостная поза удерживается; глаза и лёгкая улыбка несут основную эмоцию. |
| 70–87 | 3,50–4,35 c | Голова мягко опускается; шарф, лист и хвост догоняют основное движение. |
| 88–99 | 4,40–4,95 c | Возврат в нейтраль. Кадр 99 совпадает по силуэту и опорным точкам с кадром 0. |

Движение рисуется на единицах, но сильные позы можно удерживать 2–3 кадра. Нельзя создавать промежуточные кадры смещением цельной картинки: голова, грудная клетка, уши, глаза, хвост, шарф и лист должны проходить собственные дуги.

## Модель и взгляд

- Основной ракурс — три четверти спереди, полная фигура, одна линия пола и один масштаб во всей цепочке.
- Палитра наследует главный арт: тёмно-синяя шерсть, серо-синие светлые пряди, янтарные глаза, рыже-оранжевая грудка, шарф и кленовый лист.
- Взгляд читается через положение зрачков, форму верхнего века, размер блика и небольшую асимметрию ушей. Бровные пятна не двигаются отдельно от черепа.
- В нейтрали взгляд направлен на пользователя. В `notice` сначала движутся глаза, затем ухо и голова. В `happy` зрачки слегка поднимаются, верхние веки раскрываются, блики остаются стабильными.
- Пол компаньона меняет обращение и реплики, но не требует двух отдельных базовых скелетов. Позже различия можно добавить через причёску, форму ресниц и предметы гардероба без изменения хитбоксов.

## Слои и точки крепления

Базовая сборка: `rear_tail`, `rear_body`, `legs`, `chest`, `head`, `muzzle`, `eyes`, `eyelids`, `ears`, `front_tail`, `scarf`, `leaf`. Три слота одежды поверх неё: `head`, `body`, `gear`.

Каждый кадр хранит точки `head`, `neck`, `back`, `front_paw`, `rear_paw` и `tail_base`. Одежда следует этим точкам и получает собственную вторичную деформацию. Одновременно можно надеть не более одной вещи каждого типа, то есть максимум три разные вещи.

## Переходы между состояниями

- Все спокойные состояния входят через кадр 0 или совместимую нейтральную позу.
- Активное действие заканчивается 8–14 кадрами `settle`, а затем передаёт управление `idle`.
- Срочная эмоция может прервать `idle` только на точке перехода; кормление, вода и ласка не обрывают движение посередине.
- `sad`, `offended` и `withdrawn` имеют собственные нейтральные позы и отдельные короткие мосты из обычной нейтрали.
- Планировщик выбирает следующую цепочку заранее и не меняет `src` до готовности первого кадра перехода.

## Критерии приёмки эталона

1. Ни один кадр не обрезан на холсте 256 × 256.
2. Лапы не скользят по полу, объём головы и длина морды не скачут.
3. Кадры 0 и 99 визуально совпадают и дают бесшовный цикл.
4. Эмоция понятна без текста на размере 128 CSS px.
5. Три слоя тестовой одежды не дрожат относительно точек крепления.
6. Цепочка проигрывается ровно за 5 секунд при 20 FPS и не создаёт постоянный JavaScript-цикл в фоне.
