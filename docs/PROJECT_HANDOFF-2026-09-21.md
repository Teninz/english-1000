## 5. Уроки этих двух дней

- Bash-инструмент здесь ломается на heredoc-ах с `$(`/апострофами внутри — большие правки писать в `.py`-файл через Write
  и запускать `python файл.py`; запись в файлы репозитория иногда падает с `OSError 22` (файл занят) — повторить через секунду.
- В браузере предпросмотра service worker кэширует сайт: после правок — снять регистрацию SW, очистить `caches`,
  `fetch(f,{cache:'reload'})` для изменённых файлов, затем открывать с новым `?v=`.
- Примеры для карточек должны содержать слово в простой форме (`wordRegex`: -s/-es/-ed/-ing, e-выпадение, y→ie);
  `EXAMPLE_FORMS` в `word-forms.js` задаёт исключения (`freeze`→`froze`, `ban`→`banned` для обеих частей речи).
- `practice` уровня должен ссылаться только на ключи этого уровня (`program-check.js` это проверяет).
