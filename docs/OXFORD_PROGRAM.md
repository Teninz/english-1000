# Основная программа: Oxford 3000 по уровням A1–B2

Решение от 20.09.2026 (пункты 1 и 7 плана продолжения). Основной раздел приложения — не «1000 слов
в 20 темах», а официальный список **Oxford 3000** (A1–B2), разбитый по подтверждённым уровням и небольшим
тематическим блокам. Прежние слова, которых нет в Oxford 3000, живут в «Дополнительном словаре».

## 1. Источник и единицы

- Список — `tools/oxford-3000.json`, снят с официального PDF Oxford University Press скриптом
  `tools/import-oxford-3000.py` (sha256 PDF записан в файле; PDF в репозиторий не входит).
- **3810 единиц «слово + часть речи + уровень»** на 2977 заглавных слов: A1 1076, A2 992, B1 907, B2 835.
  Разные части речи одного слова — разные карточки (`answer|n`, `answer|v`).
- Значения, которые Oxford разделяет сам (`bank (money)` A1 / `bank (river)` B1, `light (from the sun)` /
  `light (not heavy)`, `lie1` / `lie2 (tell a lie)` …), — тоже разные карточки; короткие ярлыки значений —
  в `tools/oxford-senses.json`. Одна строка Oxford (например, `run v. A1`) — одна карточка.
- Одна опечатка PDF исправлена в `ROW_FIXES` скрипта (`produce v. A2, v. B2` → `n. B2`, сверено со словарём).

## 2. Файлы данных

| Файл | Что | Формат |
|---|---|---|
| `oxford-a1.js` … `oxford-b2.js` | контент уровня: `OXFORD_A1 = {level, blocks:[{id,title,words}], practice, confusables}` | запись `[слово, перевод, часть речи, пример, перевод примера, уточнение?]` |
| `words-extra.js` | «Дополнительный словарь»: 482 слова прежнего курса вне Oxford 3000, блоки — прежние 20 тем | генерируется `node tools/build-extra-words.js`, вручную не править |
| `program.js` | собирает `PROGRAM_LEVELS`, `WORDS`, `BLOCKS`, `WORD_KEYS`, `PRACTICE`, `CONFUSABLES`, `LEGACY_KEYS` | подключается после всех файлов слов, до `thematic-data.js` |
| `words-a.js`, `words-b.js`, `ex-ru.js` | прежний курс; нужны для переноса прогресса и для тематических маршрутов (`THEMATIC_REUSE`) | не менять порядок |

Ключ прогресса — `слово|часть речи`, для разделённых значений `слово|часть речи|ярлык` (`bank|n|money`).
Уровень и блок — свойства контейнера, не записи. `practice` — необязательная карта по ключу:
`{collocations:[[фраза, перевод]], examples:[[пример, перевод]]}`; `confusables` — пары ключей.

Состояние на 21.09.2026: **все четыре уровня готовы — 3810/3810 единиц в 144 блоках** (A1 46, A2 37, B1 32, B2 29),
плюс 20 блоков дополнительного словаря; всего 4292 карточки. `practice` для 157 слов, 246 активных близких пар.

Первая содержательная вычитка A2 выполнена 21.09.2026: проверены все 992 записи, исправлены неточные переводы,
кальки и неестественные примеры. Неработающие пары близких слов, у которых одной карточки нет в программе, удалены
из A2, B1 и B2; `program-check.js` теперь проверяет структуру `practice`, русские переводы и существование обеих
карточек в каждой паре.

## 3. Перенос прогресса (v2 → v3)

`LearningCore.migrate` (вызывается из `validate`): ключи `S.w`, `S.hard`, `days[].words/remembered`,
`stats.solvedSet`, `stats.heard.w`, `journey.plan` переименовываются по `LEGACY_KEYS` (`слово → слово|часть речи`
из `words-a/b.js`); задания дня `level` удаляются; `v` становится 3. Слово без соответствия сохраняет старый ключ.
Перенос одноразовый и идемпотентный, выполняется при загрузке и при импорте копии. Прогресс слов B1–B2 из
Oxford сохраняется под новыми ключами и станет виден, когда эти уровни получат контент.

## 4. Интерфейс

- «Учить», «Проверка → Блок», «В дороге → Уровень по выбору»: сегменты A1 · A2 · B1 · B2 · Доп., под ними плитки
  блоков уровня с прогрессом; клик по уровню выбирает первый блок с неначатыми словами.
- «Слова»: уровни как раскрывающиеся группы, внутри — блоки с полосой прогресса и сбросом блока.
- Подписи карточек: `A1 · Семья` вместо «тема 4». Достижение «Мастер» считает все слова программы.
- Виджет получает подпись блока пятым полем (`native.js`, `tools/build-web.js`).

## 5. Содержательная практика (пункт 7)

- **Сочетания** (`col`): «make a ___» + значение сочетания, четыре варианта той же части речи.
- **Близкие значения** (`cf`): предложение с пропуском и два слова из пары (`say/tell`, `much/many`); задание
  открывается, только когда оба слова начаты.
- Запасные примеры используются в «Пропуске» после первого верного ответа и для слов с флажком «сложное».
- Оба задания вплетаются в повторения с ячейки 2–3 (`kindForBox`), есть в экзамене и как отдельные режимы проверки.
- Оборот карточки показывает сочетания одной строкой, карточка слова — сочетания и дополнительные примеры.

## 6. Как добавить уровень (A2, B1, B2)

1. `node tools/program-scaffold.js A2 > список.txt` — все единицы уровня; `✓` — есть перевод и пример в прежнем
   курсе или в базовых словах маршрутов, их можно переиспользовать.
2. Собрать блоки по 20–25 единиц в `oxford-a2.js` (формат — как в `oxford-a1.js`). Пример должен содержать слово в
   простой форме (`wordRegex`: -s/-es/-ed/-ing, e-выпадение, y→ie); неправильные формы (`went`, `made`) не подходят.
3. `node tools/program-check.js A2` — полнота, дубликаты, части речи, ярлыки значений, слово в примере. Ошибок 0 и
   «не хватает 0» — уровень готов. Тест `npm test` запускает ту же проверку для всех непустых уровней.
4. Обновить `sw.js` (`CACHE`), при необходимости `PROGRAM_LEVELS[].total` не трогать — он из Oxford.

## 7. Что осталось по пунктам 1 и 7

- Независимая финальная вычитка A2 и первая содержательная вычитка B1–B2. A2 прошёл первый полный редакторский
  проход 21.09.2026; B1–B2 пока проверены формально.
- Тематические маршруты (сделано 21.09): добор до 100 слов — явные тематические ключи программы `THEMATIC_PICK`
  в `thematic-data.js` плюс новые базовые записи (visa, tram, oxygen, atom, ladder…); срезов по индексам больше нет,
  тест запрещает чужие слова (browser/spam/gossip/parliament) в маршрутах. Прогресс по выбывшим словам вычищается,
  незавершённый блиц со старым составом закрывается без блокировки. `word-levels.js` перегенерирован для новых слов.
- После этого `words-a/b.js` можно свести к компактной карте `слово → часть речи` для миграции.
