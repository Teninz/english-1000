# Пиксельная лиса-компаньон

## Готовые ресурсы

- `tools/companion-source/pixel-fox-atlas.png` — исходный атлас 4 × 4. Он не попадает в APK.
- `art/companion/<state>.png` — статичные 128 × 128 PNG для режима уменьшения движения.
- `art/companion-anim/<state>.png` — готовые APNG для приложения.
- `android/app/src/main/res/drawable-nodpi/companion_*.png` — четыре статичных состояния Android-виджета.

В лисе сохранены тёмная серо-синяя шерсть, золотые глаза, рыжий шарф и кленовый лист из главной иллюстрации. В каждый момент приложение показывает один обычный `<img>`; Canvas, WebGL, скелет и постоянный JavaScript-цикл не используются.

## Состояния

| Состояние | Сценка | Длительность |
|---|---|---:|
| `idle` | спокойное ожидание | 5 с |
| `listen` | заинтересованно слушает | 3 с |
| `happy` | радостно поднимает мордочку | 3 с |
| `pet` | принимает ласку | 3 с |
| `feed` | ест из миски | 4 с |
| `drink` | пьёт воду | 4 с |
| `hungry` | просит есть | 5 с |
| `thirsty` | просит пить | 5 с |
| `stretch` | довольно потягивается | 4 с |
| `yawn` | зевает | 4 с |
| `sleep` | спит | 7 с |
| `lesson` | играет с учебной карточкой-листом | 4 с |
| `quiet` | притихла после одного пропуска | 5 с |
| `sad` | опускает мордочку после двух пропусков | 5 с |
| `offended` | демонстративно отворачивается | 5 с |
| `withdrawn` | сидит спиной и не реагирует | 7 с |

APNG имеют временную шкалу 12 кадров/с. Движение меняется через кадр, поэтому выглядит ступенчато, как рисованная анимация на двойках. Каждый кадр — 128 × 128, общая палитра сцены ограничена 64 цветами. Все 16 APNG занимают меньше 5 МБ.

## Пересборка

```powershell
python -m pip install -r tools/requirements-art.txt
python tools/build-pixel-companion.py
node tools/build-companion-apng.js
npm test
```

`build-pixel-companion.py` удаляет нейтральный фон исходного атласа, режет его на позы, создаёт компактные статичные PNG и временные кадры. Каталог `art/companion-anim-frames/` находится в `.gitignore`. `build-companion-apng.js` собирает кадры в APNG без зависимости во время работы приложения.
