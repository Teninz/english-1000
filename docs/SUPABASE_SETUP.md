# Подключение Supabase к рейтингу

1. Создайте проект Supabase `shadowfox-eng` и сохраните пароль базы вне репозитория.
2. В **Authentication → Sign In / Providers** включите Anonymous Sign-Ins. CAPTCHA пока не включайте: текущий клиент не передаёт CAPTCHA-токен при создании анонимного профиля.
3. Откройте **SQL Editor**, вставьте содержимое `supabase/migrations/202609210001_competition.sql` и выполните запрос.
4. В окне **Connect** скопируйте Project URL и Publishable key (`sb_publishable_…`). Не используйте secret key или `service_role` в приложении.
5. В `competition-config.js` заполните только публичные значения:

```js
const COMPETITION_CONFIG = {
  url: "https://PROJECT_REF.supabase.co",
  publishableKey: "sb_publishable_..."
};
```

6. Запустите `npm test` и `npm run build:web`. В рейтинге задайте псевдоним и нажмите «Обновить». При первом обновлении приложение создаст анонимного пользователя и выдаст код дружбы.

## Что хранится в Supabase

- UUID анонимного пользователя;
- псевдоним и код приглашения;
- подтверждённые связи друзей;
- одно абсолютное число баллов на неделю;
- число ручных обновлений за серверные сутки.

Слова, ответы, ошибки, интервалы и локальная статистика не передаются.

## Ограничения первой версии

- Один профиль рейтинга привязан к одному активному устройству.
- Анонимный профиль нельзя восстановить после удаления данных приложения. Позже его можно связать с подтверждённой электронной почтой.
- При передаче только итоговой суммы сервер не может доказать честность каждого локального начисления. Ограничение подходит для закрытого дружеского рейтинга.
