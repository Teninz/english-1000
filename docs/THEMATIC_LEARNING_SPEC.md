# Тематические маршруты ShadowFox Eng

Статус: первоочередная задача после 1.0.3.5. Анимация и гардероб лисы отложены до завершения этого раздела.

## Назначение

«Тематические маршруты» — самостоятельная программа обучения внутри приложения. Она не участвует в заданиях дня, серии и прогрессе основной программы из 1000 слов. У неё собственные настройки, интервальные повторения, статистика, экзамены и достижения.

Маршруты:

| ID | Название | Содержание | Награда за блиц |
|---|---|---|---|
| `forest` | Лес | растения, животные, погода, ориентирование и безопасность | Лесной набор |
| `village` | Деревня | хозяйство, ферма, постройки, инструменты и быт | Деревенский набор |
| `travel` | Туризм | маршрут, транспорт, жильё, документы и общение в поездке | Набор путешественника |
| `city` | Город | улицы, учреждения, транспорт, услуги и городские ситуации | Городской набор |
| `beach` | Пляж | море, отдых, погода, снаряжение и безопасность на воде | Пляжный набор |
| `space` | Космос | астрономия, корабль, полёт, исследования и условия в космосе | Космический набор |
| `science` | Наука | лаборатория, измерения, эксперименты, открытия и научный метод | Научный набор |
| `rescue` | Экстренные службы | скорая помощь, пожарные, полиция, спасатели и вызов помощи | Набор спасателя |
| `shops` | Магазины | товары, размеры, деньги, возврат, доставка и общение с продавцом | Торговый набор |
| `home` | Дом и квартира | комнаты, мебель, техника, ремонт, уборка и бытовые ситуации | Домашний набор |

Каждый маршрут содержит ровно 100 уникальных английских слов и выражений. Сложность растёт внутри маршрута от A1/A2 к B2/C1. У каждой записи есть перевод, часть речи, пример, перевод примера и ступень сложности.

## Навигация

На главной появляется заметная карточка «Тематические маршруты» между заданиями дня и инфографикой. Она открывает отдельный экран, не добавляя шестую тесную кнопку в нижнюю панель.

Экран маршрутов показывает десять карточек: изучено, ожидает повторения, точность, состояние блиц-экзамена и полученную награду. Внутри маршрута доступны:

- изучение новых слов;
- отдельное повторение;
- список 100 слов и индивидуальный сброс;
- статистика маршрута;
- настройки тематического обучения;
- блиц-экзамен после выполнения условия допуска.

## Отдельные данные

Рекомендуемое поле в общей структуре прогресса:

```json
{
  "thematic": {
    "settings": {
      "batchSize": 5,
      "reviewSize": 15,
      "autoSpeak": true
    },
    "topics": {
      "forest": {
        "words": {},
        "days": {},
        "stats": { "ok": 0, "bad": 0 },
        "exam": {
          "passedAt": null,
          "attempts": 0,
          "lockedUntil": null,
          "active": null
        }
      }
    },
    "equipmentRewards": {}
  }
}
```

`thematic.topics.<id>.words` использует ту же проверенную семиячеечную схему интервальных повторений, но никогда не читает и не изменяет основной `S.w`. Поле входит в экспорт прогресса и строгую проверку импорта. Старые сохранения получают пустую тематическую структуру автоматически.

## Допуск к блицу

Рекомендуемый критерий: все 100 слов должны достичь как минимум ячейки 3 («знаю»). Так блиц нельзя открыть простым однократным просмотром всех карточек. Критерий будет явно показан на карточке: «Готово к блицу: 84/100». Окончательный порог нужно утвердить до реализации интерфейса.

## Блиц-экзамен

Перед стартом показывается обязательное предупреждение:

> В блице 100 слов в случайном порядке без повторений. На каждый ответ — 6 секунд. Пять ошибок или пропусков завершают попытку. Экзамен нельзя поставить на паузу. При сворачивании приложения время продолжает идти. Самостоятельный выход заблокирует новую попытку на 30 минут.

Кнопки: «Начать блиц» и «Вернуться к подготовке».

Правила попытки:

- один случайно перемешанный список из всех 100 слов;
- одно слово на позицию, повторов нет;
- 6 секунд на каждый ответ по абсолютному времени устройства;
- неверный ответ или истечение 6 секунд добавляет одну ошибку;
- пятая ошибка немедленно завершает экзамен неуспешно;
- 100 обработанных слов при числе ошибок от 0 до 4 означают успех;
- ручной выход завершает попытку и устанавливает `lockedUntil = now + 30 минут`;
- кнопка Android «назад» считается ручным выходом после подтверждения;
- во время попытки переходы в другие разделы и обычная пауза недоступны.

### Защита таймера

Попытка сохраняет `attemptId`, перемешанный порядок, `startedAt`, номер текущего слова, ошибки и ответы. Для каждого слова дедлайн вычисляется как абсолютное время, а не уменьшаемый счётчик. После возврата из фона приложение сравнивает текущее время с дедлайнами и отмечает все полностью пропущенные позиции ошибками. Если накопилось пять ошибок, экзамен сразу завершается.

В APK следует использовать два источника времени: `Date.now()` и нативный Android `SystemClock.elapsedRealtime()`. Для расчёта берётся больший достоверный прошедший интервал. Это защищает попытку от остановки JavaScript в фоне и простого перевода системных часов назад. После перезагрузки телефона используется сохранённое календарное время; полностью исключить ручную подмену часов в офлайн-приложении невозможно, поэтому подозрительный откат времени завершает активную попытку без выдачи награды.

Активная попытка сохраняется после каждого ответа. Принудительное закрытие приложения не создаёт паузу: при следующем запуске пропущенные интервалы пересчитываются по часам устройства.

Для первой реализации рекомендуемый ответ — выбор одного из четырёх вариантов с чередованием направлений EN → RU и RU → EN. Он подходит для ограничения в 6 секунд, одинаково работает на небольших экранах и не зависит от скорости набора текста. Окончательный формат ответа нужно утвердить до наполнения экзамена.

## Достижения и будущая одежда

Каждый успешно пройденный блиц выдаёт отдельное постоянное достижение и идентификатор комплекта:

```text
topic_forest, topic_village, topic_travel, topic_city, topic_beach,
topic_space, topic_science, topic_rescue, topic_shops, topic_home
```

Повторное прохождение не дублирует награду. Полученные достижения и комплекты не сгорают при сбросе серии или пропусках занятий.

Гардероб реализуется после тематического обучения. Уже сейчас данные награды должны хранить `equipmentSetId`, чтобы потом не мигрировать достижения. Предлагаются три совместимых слота:

- `head` — головной убор, очки или шлем;
- `body` — шарф, куртка, жилет или костюм;
- `gear` — рюкзак, сумка, прибор или другой аксессуар.

Одновременно можно надеть не более одной вещи каждого слота, всего до трёх вещей. Обычное достижение сможет выдавать одну вещь, тематический блиц — согласованный комплект из трёх слотов.

## Порядок реализации

1. Утвердить формат ответов блица и точный критерий допуска.
2. Добавить структуру данных, валидацию, импорт и тесты изоляции прогресса.
3. Подготовить и проверить 10 словарей по 100 записей.
4. Сделать каталог маршрутов, экран темы, изучение, повторение, список слов и настройки.
5. Реализовать устойчивый к фону блиц и тесты абсолютного времени.
6. Добавить десять достижений и метаданные будущих комплектов.
7. Провести полную регрессию основной программы и собрать отдельный APK для проверки.

## Критерии готовности

- во всех маршрутах ровно 100 уникальных записей, у каждой заполнены перевод и оба примера;
- основной и тематический прогресс не влияют друг на друга;
- повторения одного маршрута не попадают в другой;
- порядок блица содержит все 100 слов ровно один раз;
- фон, перезапуск и изменение экрана не останавливают время попытки;
- пятая ошибка всегда завершает попытку;
- ручной выход устанавливает блокировку ровно на 30 минут;
- достижение и `equipmentSetId` выдаются только после успешной сотой позиции;
- старые резервные копии импортируются, новые сохраняют тематический прогресс;
- прежние режимы обучения и Android-функции проходят регрессионные тесты.
