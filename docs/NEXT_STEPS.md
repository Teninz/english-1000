# Следующие шаги после 1.0.3.5

Пиксельная 2D-лиса реализована. Техническое описание находится в `docs/PIXEL_FOX_SPEC.md`, список изменений — в `docs/CHANGES-1.0.3.5.md`.

## Шаг 1. Проверить APK 1.0.3.5 на телефоне

- [ ] Боковая панель открывается ручкой и не мешает занятиям.
- [ ] 16 анимаций выглядят чётко и не вызывают рывков интерфейса.
- [ ] Кнопки «Угостить», «Напоить» и «Погладить» показывают правильные реакции.
- [ ] Через один полный пропущенный день лиса притихает, через два грустит и отворачивается, через три сидит спиной и не реагирует.
- [ ] Короткое занятие возвращает закрывшуюся лису к общению.
- [ ] Android-виджет показывает четыре ступени настроения; кнопки «Еда», «Вода» и «Ласка» синхронизируются с приложением.
- [ ] Старый прогресс после обновления сохранён.
- [ ] Светлая и тёмная темы читаемы; на маленьком экране три кнопки не обрезаются.
- [ ] «В дороге», озвучка, распознавание, задания дня, повторения и инфографика работают как раньше.

Если лаунчер показывает старую разметку виджета, удалить виджет и добавить его заново.

## Шаг 2. Выпустить обновление

1. Закоммитить изменения и отправить рабочую ветку по команде пользователя.
2. Дождаться зелёной сборки GitHub Actions или использовать локально подписанный APK.
3. Установить `ShadowFoxEng-1.0.3.5.apk` поверх 1.0.3.2/1.0.3.4 и пройти чек-лист.
4. После проверки загрузить APK в RuStore. Текст изменений находится в `about.js` и `docs/CHANGES-1.0.3.5.md`.

## Отложено

- Подсказка про оптимизацию батареи в режиме «В дороге», если конкретный телефон останавливает фон.
- Постоянная голосовая команда «окей, лиса» — только как опция из-за расхода батареи.
- Google Play и отдельная нативная версия на Kotlin — при появлении продуктовой необходимости.
