# Следующие шаги после 1.0.3.4

Порядок — по приоритету. Каждый шаг можно отдать Claude Code целиком: достаточно назвать номер.

## Шаг 1. Слить PR и получить APK 1.0.3.4

1. Открыть https://github.com/Teninz/english-1000/pull/1 → **Merge pull request** → **Confirm merge**.
2. Сборка «Android APK» запустится сама (пуш в `main`). Дождаться зелёной галочки (≈3,5 мин) на вкладке Actions.
3. Подтянуть локальную `main` и скачать APK — команды по одной:

```bash
git checkout main
```

```bash
git pull
```

```bash
gh run list --workflow "Android APK" --limit 1
```

Подставить номер запуска из первой колонки `ID`:

```bash
gh run download <ID> --dir apk/ci11
```

APK будет в `apk/ci11/ShadowFoxEng-1.0.3.4/`. Скопировать `ShadowFoxEng-1.0.3.4.apk` в `apk/` и установить на телефон.

## Шаг 3. Заменить 3D-лису на 2D

Текущая модель — низкополигональная лиса из пакета `Free/` (лицензия не найдена). В магазин с ней не идти.

Что нужно подготовить — восемь состояний в стиле лисы с главной страницы (`art/shadowfox.png`):

| Состояние | Когда показывается | Длительность (мс) |
|---|---|---|
| idle | спокойное ожидание, настроение 0 | 5000 |
| listen | при открытии панели с хорошим настроением | 3000 |
| pet | после «Погладить» | 2667 |
| feed | после «Угостить» | 3167 |
| happy | финал занятия | 2334 |
| quiet | 1 пропущенный день | 5334 |
| sad | 2 пропущенных дня | 6000 |
| withdrawn | 3+ пропущенных дня | 6667 |

Варианты получения кадров:
- **А.** Нарисовать/сгенерировать по несколько кадров на состояние (минимум 10 на APNG — это проверяет тест) и положить в `art/companion-anim-frames/<состояние>/`. Дальше `npm run build:companion-apng` соберёт `art/companion-anim/*.png`.
- **Б.** Сначала сделать 8 статичных 2D-картинок (по одной на состояние), а анимацию собрать программно из одной картинки: покачивание, моргание, движение ушей/хвоста — Claude Code может сгенерировать такие кадры из слоёв. Быстрее, чем рисовать вручную.

Что обновится при замене (делает Claude Code):
- `art/companion-anim/*.png` — 8 APNG 256×256;
- `art/companion/*.png` — 8 статичных кадров (для режима «меньше анимации»);
- `android/app/src/main/res/drawable-nodpi/companion_{idle,sad_1,sad_2,withdrawn}.png` — 4 картинки виджета;
- `FOX_ANIMATION_MS` в `journey.js`, если длительности изменятся; тест сверяет их с APNG;
- при желании — `.fox-pet` размеры в `companion.css` под новые пропорции.

После замены: `npm test`, поднять версию до `1.0.3.5`, собрать APK.

## Шаг 4. Публикация в RuStore

Только после шага 3 (или с явным решением, что 3D-модель допустима).

1. Дождаться модерации 1.0.
2. Консоль RuStore → приложение id 2063756811 → Версии → Загрузить → выбрать `apk/ShadowFoxEng-1.0.3.x.apk` (подпись та же — встанет как обновление).
3. Иконка карточки — `icons/icon-512.png`.
4. Текст «Что нового» — из `about.js` (`CHANGELOG`). Перед этим попросить Claude Code объединить записи 1.0.3.2 и 1.0.3.4 в одну публикуемую.
