# Следующие шаги: лиса-компаньон

Тематические маршруты, отдельный прогресс, блиц и награды реализованы. Текущие APNG остаются временной заглушкой: обрезка неудачна, а движение цельного спрайта выглядит неестественно.

Первоочередная задача описана в `docs/THEMATIC_LEARNING_SPEC.md`: десять независимых маршрутов по 100 слов, отдельные повторения, блиц-экзамены, достижения и задел под комплекты одежды.

## Шаг 1. Данные и изоляция прогресса

- [x] Добавить отдельное поле `thematic` в состояние и резервные копии.
- [x] Не менять основной словарь `WORDS`, прогресс `S.w`, задания дня и серию.
- [x] Добавить отдельные настройки размера порции, повторения и автоозвучки.
- [x] Покрыть миграцию старых сохранений и изоляцию тестами.

## Шаг 2. Десять словарей

- [x] Лес, деревня, туризм, город, пляж, космос, наука, экстренные службы, магазины, дом/квартира.
- [x] Ровно 100 уникальных слов и выражений в каждом маршруте.
- [x] Сложность A1/A2 → B1/B2 → C1; перевод, часть речи, пример и перевод примера обязательны.
- [x] Автоматически проверить количество, уникальность и заполненность данных.

## Шаг 3. Интерфейс обучения

- [x] Карточка «Тематические маршруты» на главной.
- [x] Каталог десяти маршрутов и экран выбранной темы.
- [x] Собственное изучение, повторение, список слов, статистика и сброс.
- [x] Весь прогресс маршрутов независим друг от друга и от основной программы.

## Шаг 4. Блиц и достижения

- [x] Допуск после первичного изучения всех 100 слов, независимо от статуса «знаю».
- [x] Предупреждение перед стартом: 100 слов, 6 секунд, 5 ошибок, без паузы, фон не останавливает время.
- [x] Случайный порядок без повторов, абсолютные дедлайны и восстановление после перезапуска.
- [x] Любой провал или ручной выход блокирует новую попытку на 30 минут; на карточке идёт визуальный обратный отсчёт.
- [x] Вопрос — английское слово, ответ — один из четырёх русских переводов.
- [x] Десять достижений с `equipmentSetId` будущих комплектов одежды.

## Шаг 5. Проверка и сборка

- [x] Автоматическая регрессия основной программы и Android-функций.
- [ ] Проверка блица при сворачивании, закрытии приложения и системной кнопке «назад».
- [ ] Отдельный тестовый APK; публикация только после проверки на телефоне.

## Текущий приоритет

1. [x] Добавить выбор «лиса / лис», сохраняемое имя и редактируемые формы склонения.
2. [x] Зафиксировать ключевые позы и тайминг первой эталонной цепочки в `docs/FOX_REFERENCE_CHAIN.md`.
3. [ ] Разделить эталон на слои и собрать 100 последовательных кадров при 20 FPS.
4. [ ] Подключить новый проигрыватель атласа с предзагрузкой перехода и статичным режимом экономии.
5. [ ] После проверки эталона выпустить остальные состояния по той же системе.
6. [ ] Добавить гардероб: слоты `head`, `body`, `gear`, не более одной вещи каждого типа.
7. [ ] Связать обычные достижения с отдельными предметами, тематические блицы — с комплектами.

## Отложено
